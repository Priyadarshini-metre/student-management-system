A console-based Student Management System developed using Core Java and Object-Oriented Programming concepts.

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- Menu-driven console application

## Technologies Used
- Core Java
- OOP Concepts
- ArrayList
- Scanner Class
- Eclipse IDE

## Project Structure

```text
StudentManagementSystem/
│
├── Main.java
├── Student.java
├── StudentManagement.java
```

## How to Run

1. Open project in Eclipse IDE
2. Run `Main.java`
3. Use menu options to manage students
